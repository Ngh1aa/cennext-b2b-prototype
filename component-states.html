02 / Behavior

Static specimens for Figma and handoff. Existing live states are preserved, while error, success, selected and saved states extend the same industrial language for a complete component library.

01 / Button

Default → Hover → Pressed → Disabled

Primary CTAs use amber for urgency. Hover lifts the control, active state settles it into the surface, and disabled reduces emphasis without changing geometry.

Primary CTADefault

Amber fill, navy text, hard edge.

Primary CTAHover

Lift 3px and lighten surface.

Primary CTAPressed

Translate down 1px, scale .975.

Primary CTADisabled

38% opacity and no pointer action.
