User Flow.

04 / Journeys

Four primary journeys cover the most likely B2B intent: repair a failed asset, evaluate repair versus replacement, structure repeat-volume support, or validate GIE before making contact.

Flow 01 / Urgent repair

Problem → Capability → Contact → Action

The highest-intent path keeps urgency visible and asks only for enough motor context to start a useful service conversation.

Flow 02 / Decision support

Home → Repair vs. Replace → Matrix → Second opinion

This path is for maintenance teams that already know the motor has a problem but need help choosing the economically and operationally practical next step.

Flow 03 / Volume program

Plant need → Program fit → Process → Consultation

Repeat-volume customers care about logistics and coordination as much as technical repair. The journey therefore moves from program fit to a repeatable operating rhythm.
