## Page composition strategy
- `services.html`: capability matrix + repair process + failure-cause editorial split.
- `programs.html`: logistics/process page for recurring plant support.
- `repair-vs-replace.html`: decision-first split hero + evaluation cards + comparison matrix.
- `why-gie.html`: credibility/history page using oversized founding year + proof cards + facility facts.
- `contact.html`: emergency strip + sticky contact information + request form + routing cards.

Photography remains sourced from the high-resolution Unsplash/Pexels set already documented in `IMAGE_SOURCES.md`.
